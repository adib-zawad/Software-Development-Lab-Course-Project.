# Software Development Lab Course Project

A web-based software project developed as part of the Software Development Lab course.

## 📌 Project Overview
This project is designed to demonstrate CRUD operations, user management, admin panel functionality, and database integration using PHP, HTML, CSS, and MySQL.

## 🚀 Features
- User Registration & Login System
- Admin Dashboard
- Add, Edit, Delete Users
- Add, Edit, Delete Posts
- Car Management System
- Responsive User Interface
- Database Connectivity with MySQL
- Session Management & Authentication

## 🛠️ Technologies Used
- HTML5
- CSS3
- PHP
- MySQL
- JavaScript

## 📂 Project Structure
- `admin_*.php` → Admin functionalities
- `add_cars.php` → Add car information
- `admin_login.php` → Admin login system
- `*.css` → Styling files
- Database files → MySQL integration
